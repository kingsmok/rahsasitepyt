# سیستم رنگ استاندارد پروژه

هدف: همهٔ رنگ‌ها از یک منبع واحد بیایند تا تغییر پالت در `/admin/designs`
کل سایت را یکدست عوض کند و هیچ صفحه‌ای از قالب عقب نماند.

## قانون طلایی

> در CSS و قالب‌ها **هرگز** رنگ ثابت (مثل `#2563eb`) ننویسید.
> همیشه از توکن استفاده کنید: `var(--primary)`.

استثنای مجاز فقط رنگ برندهای بیرونی است (مثل سبز واتساپ `#25d366`
یا آبی تلگرام `#229ed9`) که ماهیتاً نباید با پالت سایت عوض شوند.

## توکن‌های اصلی

| توکن | کاربرد |
|---|---|
| `--primary` | رنگ اصلی برند؛ دکمه‌ها، لینک فعال، تأکید |
| `--primary-2` | حالت تیره‌تر برای hover و گرادیان |
| `--primary-soft` | پس‌زمینهٔ کم‌رنگ (بج، هایلایت) |
| `--accent` | رنگ مکمل؛ تخفیف، نشان ویژه |
| `--accent-soft` | پس‌زمینهٔ کم‌رنگ مکمل |
| `--success` / `--success-soft` | موفقیت، تأیید، پرداخت‌شده |
| `--danger` / `--danger-soft` | خطا، حذف، هشدار قرمز |
| `--warning` | هشدار نارنجی |
| `--info` | اطلاع‌رسانی |

### سطوح و متن

| توکن | کاربرد |
|---|---|
| `--bg` / `--bg-2` | پس‌زمینهٔ صفحه و بخش‌های متناوب |
| `--card` / `--card-2` | سطح کارت‌ها |
| `--border` / `--border-2` | خطوط جداکننده و حاشیهٔ ورودی‌ها |
| `--text` | متن اصلی |
| `--text-2` | متن ثانویه |
| `--text-3` | متن کم‌اهمیت، راهنما |

### نواحی ویژه

`--header-bg`، `--header-text`، `--hero-bg`، `--hero-text`،
`--footer-bg`، `--footer-text`، `--footer-head`

### شکل و سایه

`--radius-sm` (۸px) · `--radius-md` (۱۴px) · `--radius-lg` (۲۲px) ·
`--radius-full` · `--shadow-sm` · `--shadow-md` · `--shadow-lg`

## کنتراست و دسترس‌پذیری

روی پس‌زمینهٔ رنگی از `--on-primary` و `--on-accent` استفاده کنید؛
این دو تضمین می‌کنند متن روی رنگ برند خوانا بماند.

برای متن‌های ریز روی پس‌زمینهٔ روشن، `color-mix` کنتراست را تضمین می‌کند:

```css
color: color-mix(in srgb, var(--primary) 55%, var(--text));
```

## پالت‌های آماده

۲۰ پالت ایرانی دست‌چین‌شده در `persian_palettes.py` تعریف شده‌اند
(فیروزه‌ای اصفهان، زعفرانی قائنات، لاجوردی شیراز، اناری یزد و…).
هر پالت ۵ رنگ پایه + توکن‌های دستی دارد و بقیهٔ توکن‌ها از آن‌ها مشتق می‌شوند.

انتخاب پالت: **پنل مدیریت → طراحی‌ها** (`/admin/designs`).

## افزودن استایل جدید

```css
/* ✅ درست */
.my-box {
  background: var(--card);
  border: 1px solid var(--border);
  border-radius: var(--radius-md);
  color: var(--text);
  box-shadow: var(--shadow-sm);
}

/* ❌ غلط — با تغییر پالت خراب می‌شود */
.my-box {
  background: #ffffff;
  border: 1px solid #e2e8f0;
  border-radius: 14px;
  color: #0f172a;
}
```

## بهینه‌سازی دارایی‌ها

فایل‌های CSS/JS با اسکریپت زیر فشرده می‌شوند:

```bash
python scripts/build_assets.py
```

خروجی `*.min.css` و `*.min.js` کنار فایل اصلی ساخته می‌شود و تابع
`asset()` در قالب‌ها خودکار نسخهٔ فشرده را انتخاب می‌کند. اگر فایل اصلی
تازه‌تر از نسخهٔ فشرده باشد (یعنی بعد از build ویرایش شده)، به‌صورت خودکار
فایل اصلی سرو می‌شود تا هرگز کد کهنه نمایش داده نشود.

این مرحله در به‌روزرسانی خودکار (`updater.py`) هم اجرا می‌شود.

> ⚠️ فشرده‌سازی gzip در زمان اجرا عمداً خاموش است
> (`ENABLE_GZIP=0`). روی cPanel/Passenger، nginx خودش خروجی را فشرده
> می‌کند و فشرده‌سازی مضاعف باعث خطای ۵۰۳ می‌شد.
