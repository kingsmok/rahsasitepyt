## ۶) نقشه صفحات (ساختار جدید)

### صفحه اصلی — ۷ سکشن (از ۱۱ فعلی؛ از طریق صفحهساز)
1. **Hero** (کوتاهتر: عنوان + زیرعنوان + CTA + ۱ تصویر) ← ادغام اسلایدر ۲تایی به ۱
2. **اعتماد** (۳ آمار کلیدی بهجای ۵ + نمادها)
3. **دورههای منتخب** (۴ کارت)
4. **چرا آکادمی** (۳ ویژگی بهجای ۶)
5. **داستان موفقیت** (۲-۳ کارت)
6. **نظرات واقعی** (۳)
7. **CTA پایانی** (+ خبرنامه داخل فوتر)

### صفحه دوره — ترتیب اصلاحشده
عنوان+مدرس → ویدیو معرفی → CTA خرید (چسبان در موبایل) → دستاوردها → سرفصلها → مدرس → نظرات → FAQ → دورههای مرتبط
**حذف:** شمارنده جعلی · **اضافه:** وضعیت ثبتنام کاربر، آخرین بهروزرسانی

### پنل دانشجو — کارمحور
«ادامه یادگیری» (بزرگ) → دورههای من با پیشرفت → تکالیف/آزمونهای پیشرو → اعلانها → گواهیها
**انتقال به صفحات ثانویه:** تراکنشها، علاقهمندیها، تنظیمات

### پنل مدرس
داشبورد متراکم (فروش + دانشجو + نمرهدهی) → دورهها → تکالیف → پرسشها → درآمد

### ✅ فاز ۲ — اسلایدر چندتصویری + بازنویسی کامل ادیتور (به سبک المنتور)
پاسخ به درخواست بازنویسی دقیق «مثل المنتور»:
- **معماری iframe**: بوم ویرایش داخل iframe رندر میشود → پیشنمایش دستگاهها (دسکتاپ/تبلت/موبایل) واقعی و دقیق است
  (media queryها به عرض iframe پاسخ میدهند؛ مشکل «فقط موبایل نشان میداد» ریشهای حل شد).
- **پنل راست با سه تب**: محتوا / استایل / پیشرفته (مثل المنتور) + گروههای بازشو.
- **تب استایل**: تراز، رنگ متن/پسزمینه، عرض، گردی گوشه، margin/padding چهارطرفه — در `d.style` ذخیره و در رندر عمومی اعمال میشود.
- **درگانددراپ واقعی**: ویجت از پالت به ستونها، جابهجایی ویجت بین ستونها با دستگیره، جابهجایی سکشنها با دستگیره ردیف،
  خط نشانگر درج، ghost دنبالکننده ماوس، کلیک-برای-افزودن (حالت مسلح) برای موبایل/دسترسیپذیری.
- **نوار «افزودن سکشن»** بین همه سکشنها + مدال چیدمان ۱ تا ۷ ستون + سکشنهای آماده (مثل المنتور).
- **ناویگیتور** (درخت ساختار صفحه) با اسکرول و انتخاب همزمان.
- **اسلایدر**: با ۳ اسلاید نمونه پیشفرض ساخته میشود؛ افزودن/حذف/کپی/جابهجایی اسلاید با کارتهای بازشو + تصویر از کتابخانه رسانه یا آپلود؛

- **کتابخانه رسانه**: مدال انتخاب تصویر با آپلود (فیکس باگ `jdate_num` و `jdatetime` در APIها).
- **ویرایش درونخطی**: دابلکلیک روی متنها در بوم + contenteditable با ذخیره خودکار در blur.
- **دکمهها و میانبرها**: Ctrl+S ذخیره، Ctrl+Z/Y واگردانی، Delete حذف، Ctrl+C/V/D کپی/پیست/تکثیر، Esc لغو.

## 🔧 فیکس بحرانی — تداخل فیلد «style» (۱۴۰۵/۰۵/۱۵)

### مشکل
هنگام افزودن/ویرایش ویجتهای **دکمه، جداکننده، CTA و افزودنبهسبد** در صفحهساز خطای
`'str object' has no attribute 'get'` در رندر ردیف ظاهر میشد.

### علت ریشهای
این ۴ ویجت یک فیلد متنی به نام `style` داشتند (مثل `style='primary'`)؛ تب «استایل» جدید
صفحهساز هم تنظیماتش را در `d.style` (آبجکت) ذخیره میکرد → تداخل: ماکرو `widget_style`
روی رشته `s.get(...)` صدا میزد و کرش میکرد.

### راهحل (انجام شد)
1. **تغییر نام فیلدها** برای رفع تداخل:
   - `button` و `add_to_cart`: `style` ← `btn_style`
   - `divider`: `style` ← `line_style`
   - `cta`: `style` ← `cta_style`
2. **پشتیبانی از داده قدیمی**: ماکروهای قالب با `(d.btn_style or (d.style if d.style is string else ''))`
   سازگارند و `_sanitize_widget` + `init()` ادیتور دادههای ذخیرهشده قدیمی را مهاجرت میدهند.
3. **گارد ماکرو `widget_style`**: `d.style is mapping` — حتی اگر داده ناسازگار بماند کرش نمیکند.
4. **دفاع تب استایل**: اگر `d.style` رشته بود به آبجکت خالی تبدیل میشود (خطای strict-mode هم رفع شد).
5. **بهبودهای همراه**:
   - Escape داخل بوم به سند والد فوروارد میشود (لغو حالت مسلح از داخل iframe).
   - در حالت مسلح (کلیک-برای-افزودن) خروج با Esc یا کلیک دوباره روی ویجت پالت.
   - باگ `pending.type` بعد از null شدن (کلیک-برای-افزودن اصلاً کار نمیکرد) رفع شد.

### تستها (سبز)
- E2E مرورگر: دکمه/جداکننده/CTA — افزودن، انتخاب استایل، تب استایل، ذخیره، رندر عمومی ← همه پاس، صفر خطای JS
- pytest 27 پاس · سلامت 123 · مسیریاب 186 GET + 12 POST = ALL GOOD ✅

## 🔧 فیکس نهایی خطای `'str object' has no attribute 'get'` (۱۴۰۵/۰۵/۱۶)

### ریشهیابی با فاز کامل (Fuzzing)
۴۲۰ حالت تست روی هر ۸۲ ویجت با دادههای خراب (style رشته، فیلدها لیست/دیکته/None،
آیتمهای ریپیتر رشته، settings رشته، cols دیکته، inner_section خراب) اجرا شد. دو باگ واقعی پیدا و رفع شد:

1. **قالب user_dashboard**: از `u.tickets` و `u.orders` استفاده میکرد که روی مدل User نبود →
   خطای `'models.User object' has no attribute 'tickets'` (باگ واقعی، خارج از سناریوی کاربر اما جدی).
   → اضافهکردن backref های `orders` و `tickets` به مدلهای Order/Ticket.
2. **تابع `uniq_cats`** (ویجت portfolio): `(it or {}).get('category')` — اگر `it` رشته بود
   دقیقاً `'str object' has no attribute 'get'` میداد → گارد `isinstance(it, dict)`.

### دفاع نهایی (چندلایه)
- **تبدیل اجباری نوع همه فیلدها در `_sanitize_widget`** (مثل المنتور):
  فیلدهای متنی/انتخابی/رنگ/تصویر → همیشه `str` · checkbox → `bool` · number → `int` · repeater → فقط dict.
  دیگر هیچ قالبی نمیتواند داده ناسازگار ببیند؛ حتی لیست/دیکته/عدد هم به رشته امن تبدیل میشوند.
- **گارد حلقههای باقیمانده**: topbar (right/left)، nav_menu و link_list (links)، فرم (fields) → `if it is mapping`.
- **`uniq_cats` ایمن** برای آیتمهای غیردیکته.
- **آبجکت `style` تب استایل**: همیشه دیکشنری امن (رشته قدیمی در ویجتهای غیرمهاجر → `{}`).
- **فیکس `log_exc`**: فراخوانی اشتباه `exc_info` که باعث 500 و پنهانشدن خطای اصلی ردیف میشد → اصلاح شد.
- **پیام خطای رندر شفافتر** + ثبت در لاگ سرور (`builder.render_row`).

### نتیجه
- ۴۲۰ مورد فاز: صفر خطای واقعی (فقط 429 = rate limit تست).
- ۸ مورد قبلاً خطادار (user_dashboard، portfolio، topbar، nav_menu، form، slider، button، settings) → همه OK ✅
- E2E مرورگر ۱۱/۱۱ ✅ · pytest 27 ✅ · سلامت 123 ✅ · مسیریاب 185 GET + 12 POST ✅
- بکاپ: `instance/backups/academy-20260807-0951.db`

### راهنمای کاربر
اگر هنوز خطا دیده میشود: **Ctrl+Shift+R** (رفرش سخت) — JS صفحهساز ۷ روز کش میشود و تب قدیمی
باید بسته و دوباره باز شود. با این نسخه، داده خراب به هر شکلی برسد، ردیفها بدون خطا رندر میشوند.
