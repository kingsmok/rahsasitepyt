## ۱) اصول طراحی و هویت بصری

| اصل | تعریف عملیاتی |
|---|---|
| **ایرانی مدرن** | تایپوگرافی وزیرمتن با اعداد فارسی، چیدمان راست‌به‌چپ با logical properties، پرهیز از تزئینات سنتی؛ حس معاصر و «سطح بالا» |
| **مینیمال و خنثی** | پالت پایه خنثی (Slate) + فقط یک رنگ برند + یک رنگ تکمیلی؛ هیچ رنگ اضافه‌ای بدون نقش |
| **اعتمادساز** | قیمت شفاف، نمادهای رسمی، گواهی قابل استعلام، ضمانت بازگشت، بدون عدد و آمار جعلی |
| **کاربرپسند** | حداکثر ۳ کلیک تا هدف (دوره → جزئیات → ثبت‌نام)؛ فرم‌های کوتاه؛ بازخورد فوری |
| **فروش هوشمند** | هر صفحه یک هدف و یک CTA اصلی دارد؛ عناصر کمکی تبدیل (فومو، اثبات اجتماعی، کاهش ریسک) بدون شلوغی |

**قوانین طلایی چیدمان**
- هر سکشن فقط **یک پیام اصلی** و **یک CTA اولویت‌دار** دارد.
- تراکم بصری: در دسکتاپ حداکثر ۳ سطح عمق (پس‌زمینه / کارت / عنصر داخل کارت).
- ریتم عمودی سکشن‌ها: `--ds-section-py` (clamp 48–88px) و سکشن‌های فشرده `--ds-section-py-sm`.
- تناوب پس‌زمینه: روشن ↔ خنثی (`--bg` ↔ `--card`) برای تفکیک سکشن‌ها بدون خط جداکنندهٔ اضافی.

## ۲) دیزاین سیستم — توکن‌ها و کامپوننت‌ها

فایل مرجع: `static/css/design-system.css` (بعد از تم لود می‌شود؛ با **هر تم رنگی** سازگار است).

### ۲.۱ توکن‌های طراحی (Design Tokens)

| گروه | توکن‌ها | مقیاس |
|---|---|---|
| **تایپوگرافی** | `--ds-fs-xs … --ds-fs-5xl` | 11 تا 46px با مقیاس مدولار ۱.۲۵ + `clamp` برای تیترها |
| **وزن فونت** | `--ds-fw-normal … --ds-fw-black` | 400 تا 800 (وزیرمتن Variable) |
| **فاصله‌گذاری** | `--ds-sp-1 … --ds-sp-20` | مقیاس ۴ پیکسلی: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80 |
| **گردی گوشه** | `--ds-radius-xs … --ds-radius-full` | 6, 10, 14, 20, 26, 999 — هماهنگ با `kit_radius` مدیر |
| **سایه** | `--ds-shadow-xs … --ds-shadow-xl` + `brand` و `accent` | ۵ سطح + سایهٔ رنگی برند + حلقهٔ فوکوس `--ds-ring` |
| **انتقال** | `--ds-t-fast / --ds-t / --ds-t-slow` | easing استاندارد و out |
| **لایه‌بندی** | `--ds-z-dropdown … --ds-z-toast` | 250 تا 1000 |
| **معیار خوانایی** | `--ds-measure: 68ch` | حداکثر طول سطر متن بدنه |
| **رنگ‌های نقطه‌ای** | `--ds-star` (امتیاز)، `--ds-sale` (تخفیف/فروش) | قرمز رز برای قیمت تخفیف‌دار — عرف فروشگاه‌های ایرانی |

### ۲.۲ کامپوننت‌های پایه (همه در CSS سراسری)

| دسته | کامپوننت‌ها |
|---|---|
| **دکمه‌ها** | primary / accent / outline / soft / ghost / white + سایزهای sm→xl + `btn-icon` + `btn-block` + حالت لودینگ |
| **فرم‌ها** | `ds-field` (label+hint+error)، اینپوت آیکون‌دار، سوییچ `ds-switch`، چک‌باکس/رادیو مدرن، OTP، جستجو |
| **نمایش داده** | badge، chip، tag، قیمت `ds-price` (قبل/بعد/تومان)، امتیاز ستاره‌ای، شمارش معکوس `ds-count` |
| **کارت‌ها** | `ds-card` (+ lift / soft / glass / brand)، کارت دوره v2، کارت محصول |
| **بازخورد** | alert پنج‌رنگ، toast، نوار وضعیت، empty state `ds-empty`، skeleton |
| **ناوبری** | تب `ds-tabs` (+pill)، آکاردئون بومی `ds-acc` (details)، بردکرامب، مراحل `ds-steps`، پیشرفت `ds-progress` |
| **داده** | جدول `ds-table` و `ds-compare`، صفحه‌بندی، آواتار (sm→lg + ring + stack) |
| **سطح بالا** | مودال، دراور، دراپ‌داون، تولتیپ |

### ۲.۳ حالت تیره (Dark Mode)

- فعال‌سازی: `document.documentElement.dataset.theme = 'dark'` — کل توکن‌های خنثی برعکس می‌شوند (`html[data-theme="dark"]` در دیزاین سیستم آماده است).
- رنگ برند دست‌نخورده می‌ماند؛ فقط سطوح خنثی و سایه‌ها تیره می‌شوند تا هویت حفظ شود.

### ۲.۴ ریتم ریسپانسیو استاندارد

| بریک‌پوینت | رفتار |
|---|---|
| ≤ 768px (موبایل) | گرید تک‌ستونه، پدینگ سکشن نصف، CTA تمام‌عرض، نوار پایین موبایل |
| 769–1024px (تبلت) | گرید ۲ ستونه، منوی همبرگری، کارت‌های افقی مجاز |
| ≥ 1025px (دسکتاپ) | گرید کامل ۳–۶ ستونه، اسکرول نامحدود، هاور پیشرفته |

## ۳) معماری صفحه‌ساز و قابلیت‌های ویرایش (۱۰۰٪)

هر صفحه از **ردیف (سکشن) → ستون → ویجت (بلوک)** ساخته می‌شود. هیچ بخشی قفل نیست و همه‌چیز از سه تب ویرایش می‌شود:

### تب «محتوا» (مخصوص هر بلوک)
ویرایش تیتر، زیرتیتر، متن‌ها، تصویر، ویدیو، آیکون، لیست آیتم‌ها (Repeater با افزودن/حذف/جابه‌جایی)، لینک‌ها، تعداد و منبع دادهٔ داینامیک.

### تب «استایل» (عمومی همهٔ بلوک‌ها)
| قابلیت | جزئیات |
|---|---|
| تراز محتوا | راست / وسط / چپ |
| عرض | تمام‌عرض، ۵۰–۷۵٪، 400/600px |
| رنگ متن و پس‌زمینه | کالرپیکر + ورودی HEX |
| رنگ حاشیه (Border) | کالرپیکر |
| **Border Radius** | عدد آزاد (px) |
| **Shadow** | بدون / ملایم / متوسط / برجسته / رنگی برند |
| فاصله داخلی | Padding چهارجهته (بالا/راست/پایین/چپ) |
| فاصله خارجی | Margin چهارجهته |

### تب «پیشرفته»
- **نمایش در دستگاه‌ها**: مخفی در موبایل 📱 / مخفی در تبلت 📲 / مخفی در دسکتاپ 🖥 (جدا برای هر ویجت و هر سکشن)
- انیمیشن ورود (محو/زوم/اسلاید)
- کلاس CSS و ID سفارشی برای توسعه‌دهنده

### سطح سکشن (ردیف)
پس‌زمینه (رنگ/تصویر)، radius، پدینگ، مارژین، **تعداد ستون ۱ تا ۷**، عرض آزاد ستون‌ها (مثل `2fr 1fr`)، فاصلهٔ بین ستون‌ها، کپی/قفل/جابه‌جایی/حذف، ذخیره در **کتابخانهٔ سکشن‌ها** برای استفادهٔ مجدد.

## ۴) کتابخانه بلوک‌ها

### ۴.۱ بلوک‌های جدید نسخهٔ ۲ (۱۳ بلوک — همگی با فیلدهای کامل ویرایش)

| بلوک | کاربرد | فیلدهای کلیدی محتوا |
|---|---|---|
| 🏛 **معرفی برند/آکادمی** (`brand_intro`) | چرا شما؟ — تصویر/ویدیو + متن + امتیاز + آمار | برچسب، تیتر، زیرتیتر، تصویر **یا ویدیو**، نشان روی تصویر، امتیازها (خط‌به‌خط)، ۲ دکمه با استایل انتخابی، چیدمان (تصویر چپ/راست)، آمار پویا `{courses}` |
| 👤 **معرفی مدرس** (`instructor`) | اعتبارآفرینی برای مدرس دوره | نام، عنوان شغلی، آواتار، بیو، دستاوردها، آمار (دوره/رضایت)، شبکه‌های اجتماعی، دکمه |
| 📋 **سرفصل دوره/محصول** (`curriculum`) | شفاف‌سازی محتوای خرید | منبع **دستی یا داینامیک از دورهٔ فعلی**، فصل‌ها + جلسات (`عنوان \| مدت`)، باز بودن فصل اول، دکمه |
| 🗺 **مسیر یادگیری** (`learning_path`) | گام‌به‌گام تا تخصص | برچسب، تیتر، زیرتیتر، تعداد گام (۳–۵)، گام‌ها با وضعیت (عادی/تکمیل/فعلی) و برچسب |
| 🕐 **تایم‌لاین** (`timeline`) | تاریخچه/فرایند/مسیر شغلی | رویدادها (تاریخ، عنوان، توضیح)، راست‌چین/وسط‌چین |
| ⚖️ **مقایسهٔ پلن‌ها** (`plans_compare`) | جدول تصمیم‌گیری | پلن‌ها (نام، قیمت، دکمه، ستون ویژه)، سطرهای ویژگی (`عنوان \| 1 \| 0`) |
| 💎 **عضویت ویژه** (`membership`) | اشتراک/پلن‌های پولی | پلن‌ها با قیمت قبلی خط‌خورده، روبان «پیشنهاد ما»، ویژگی‌ها، دکمه |
| 🏷️ **بنر تخفیف** (`discount_banner`) | کمپین فروش با فومو | برچسب درصد، تیتر، متن، **کد تخفیف با یک کلیک کپی**، **شمارش معکوس تاریخ‌دار**، رنگ پس‌زمینه |
| 📥 **دانلود فایل** (`file_download`) | جزوه/سورس/محتوای رایگان مغناطیسی | آیکون، نام، توضیح، فرمت، حجم، لینک، ستون‌بندی |
| 🏅 **مدارک و گواهی‌ها** (`certificates`) | ارزش مدرک + استعلام | گواهی‌ها (آیکون/تصویر، عنوان، توضیح)، دکمهٔ **استعلام گواهی** |
| 🛡️ **باکس اعتمادسازی** (`trust_box`) | ضمانت/پرداخت امن/پشتیبانی | آیتم‌ها (آیکون، عنوان، توضیح)، ستون‌ها |
| 🔥 **پیشنهادهای ویژه** (`special_offers`) *داینامیک* | دوره‌های تخفیف‌دار واقعی | تعداد، ستون‌ها، دکمهٔ «همهٔ تخفیف‌ها» — از دیتابیس، بیشترین تخفیف اول |
| 🧩 **محصولات مرتبط** (`related_products`) *داینامیک* | Upsell کنار محتوا | دستهٔ محصول، تعداد، ستون‌ها |

### ۴.۲ بلوک‌های موجود که در دیزاین جدید بازآرایی شده‌اند

Hero/اسلایدر، ویدیو پس‌زمینه، جستجوی دوره، دسته‌بندی‌ها، گرید دوره‌ها، گرید محصولات فروشگاه، بسته‌های آموزشی، اساتید، ویژگی‌ها، آمار پویا، نظرات، داستان موفقیت، نظرات واقعی، FAQ، قیمت‌گذاری، CTA، خبرنامه، نمادهای اعتماد، گالری، ویدیو، شمارش معکوس، فرم‌ساز، تب‌ها، آکاردئون، تایم‌لاین آیکونی، آیکون‌باکس، پیشرفت، شمارنده، کد، امبد، اشتراک‌گذاری و … (مجموعاً **۱۰۵+ بلوک** در ۱۰ دسته).

## ۵) مشخصات کامل صفحات

> ساختار هر برگه: **هدف | سکشن‌ها | اجزا | کامپوننت‌ها | ویرایش از صفحه‌ساز | UX | UI | ریسپانسیو | CTA | اعتمادسازی | تبدیل**

### ۵.۱ صفحه اصلی
- **هدف:** ایجاد اعتماد در ۵ ثانیه اول + هدایت به «یافتن دوره» یا «ثبت‌نام رایگان».
- **سکشن‌ها (قالب آمادهٔ «مدرن ۲۰۲۶» — طرح ۶):**
  1. هیرو متنی + جستجوی زندهٔ دوره
  2. نوار اعتمادسازی ۴تایی (ضمانت بازگشت، پرداخت امن، پشتیبانی، دسترسی دائمی)
  3. معرفی برند/آکادمی (`brand_intro`) — تصویر + آمار پویا
  4. دسته‌بندی‌ها (۸ کارت آیکونی)
  5. پیشنهادهای ویژه (`special_offers`) — دوره‌های تخفیف‌دار واقعی
  6. مسیر یادگیری (`learning_path`) — ۴ گام متصل
  7. گرید دوره‌های منتشرشده (۸ کارت v2)
  8. اساتید
  9. مدارک و گواهی‌ها (`certificates`) + دکمهٔ استعلام
  10. نظرات واقعی دانشجویان (از دیتابیس)
  11. FAQ (۴ سوال کلیدی خرید)
  12. CTA ثبت‌نام رایگان
- **کامپوننت‌ها:** `ds-eyebrow`، `ds-section-head`، کارت دوره v2، `ds-trust-item`، `ds-path`، `ds-cert`
- **ویرایش:** تمام سکشن‌ها قابل جابه‌جایی/حذف/کپی؛ متن‌ها، رنگ‌ها، تعداد ستون‌ها، آمار پویا، نمایش در موبایل/تبلت/دسکتاپ.
- **UX:** جستجو در همان هیرو (کوتاه‌ترین مسیر «نیاز → دوره»)؛ فقط اسکرول، بدون انیمیشن مزاحم.
- **UI:** هیرو بدون اسلایدر شلوغ — تیتر بزرگ `--ds-fs-5xl` + جعبهٔ جستجوی برند‌رنگ؛ سکشن‌ها با تناوب پس‌زمینهٔ روشن/کارت.
- **ریسپانسیو:** هیرو تک‌ستونه، جستجو تمام‌عرض، گرید ۴→۲→۱، مسیر یادگیری خطوط اتصال در موبایل حذف.
- **CTA:** «مشاهدهٔ دوره‌ها» (اصلی) + «ثبت‌نام رایگان» (ثانویه).
- **اعتمادسازی:** آمار واقعی دیتابیس، نظرات تاییدشده، گواهی قابل استعلام، نمادها در فوتر.
- **تبدیل:** سکشن تخفیف با فومو ظریف؛ اعتماد قبل از گرید دوره؛ CTA پایانی با وعدهٔ «اولین جلسه رایگان».

### ۵.۲ صفحه دوره‌ها (لیست)
- **هدف:** پیدا کردن سریع دورهٔ مناسب با جستجو/فیلتر/مرتب‌سازی.
- **سکشن‌ها:** هدر لیست (عنوان + شمارش نتیجه) | نوار جستجو + فیلترها (دسته، سطح، نوع برگزاری آنلاین/آفلاین/حضوری، قیمت، مرتب‌سازی) | گرید کارت‌ها | صفحه‌بندی | پیشنهاد ویژه (اختیاری).
- **کامپوننت‌ها:** chip فیلتر فعال، `ds-empty` برای «نتیجه‌ای نیست»، skeleton هنگام لود.
- **ویرایش:** بالای لیست (تیتر/زیرتیتر/بنر) از صفحه‌ساز؛ نوار فیلتر رفتار ثابت تراکنشی دارد تا UX خرید نشکند.
- **UX:** فیلترها همیشه دیده شوند (بدون کلیک اضافه)؛ نتیجهٔ جستجو با شمارنده؛ پاک‌کردن یکتایی فیلترها.
- **UI:** کارت v2 — دسته + نوع برگزاری، عنوان دوخطی، متا با آیکون (امتیاز/دانشجو/ساعت)، قیمت با درصد تخفیف قرمز رز.
- **CTA:** هر کارت «مشاهدهٔ دوره» + آیکون سبد.
- **تبدیل:** مرتب‌سازی «ارزان‌ترین» و «محبوب‌ترین»؛ برچسب «ویژه/رایگان/٪تخفیف» روی کارت.

### ۵.۳ صفحه جزئیات دوره
- **هدف:** حذف تردید و رساندن به ثبت‌نام/افزودن به سبد.
- **سکشن‌های فروش‌محور:**
  1. بردکرامب + عنوان + متا (مدرس، امتیاز، دانشجو، مدت، نوع برگزاری)
  2. پخش‌کنندهٔ ویدیوی معرفی (پیش‌نمایش رایگان)
  3. **باکس خرید چسبان (Sticky)** — قیمت، تخفیف، دکمهٔ اصلی، ضمانت ۷ روزه، لینک مشاوره
  4. توضیحات (متن ساختاریافته)
  5. **سرفصل کامل** (`curriculum` داینامیک — فصل/جلسه/مدت/پیش‌نمایش رایگان)
  6. معرفی مدرس (`instructor`)
  7. پیش‌نیازها و خروجی دوره (لیست آیکونی)
  8. نظرات واقعی + امتیاز تفکیکی
  9. گواهی پایان دوره (`certificates`)
  10. محصولات مرتبط / دوره‌های مرتبط
  11. FAQ مخصوص دوره
- **ویرایش:** کل قالب از صفحه‌ساز «قالب صفحهٔ دوره» قابل بازآرایی است؛ سرفصل دستی یا داینامیک.
- **UX:** باکس خرید همیشه در دید (دسکتاپ: چسبان؛ موبایل: نوار پایین)؛ «شروع یادگیری» برای خریدار قبلی.
- **UI:** سرفصل با آکاردئون جمع‌شونده + جمع ساعت/جلسه؛ قیمت تخفیف با عدد خط‌خورده و برچسب درصد.
- **CTA:** «ثبت‌نام و شروع یادگیری» (اصلی) — برای دورهٔ رایگان: «شروع رایگان».
- **اعتمادسازی:** مدت دسترسی، ضمانت بازگشت، مشخصات مدرس، پیش‌نمایش رایگان.
- **تبدیل:** پاسخ به ۴ تردید رایج (محتوا؟ سرفصل — کیفیت؟ پیش‌نمایش — ریسک؟ ضمانت — نتیجه؟ نظرات/گواهی).

### ۵.۴ صفحه محصولات (فروشگاه)
- مثل لیست دوره‌ها؛ برچسب موجود/ناموجود، مرتب‌سازی قیمت، دستهٔ محصولات. کارت با تصویر ۱:۱ و قیمت.

### ۵.۵ صفحه جزئیات محصول
- **سکشن‌ها:** گالری تصاویر | اطلاعات خرید (قیمت، موجودی، تعداد، دکمهٔ سبد) | مشخصات در جدول `ds-table` | توضیحات | نظرات | **محصولات مرتبط** (`related_products`).
- **UX:** افزودن به سبد بدون رها کردن صفحه (toast تایید + رفتن به سبد)؛ مشخصات جدولی برای تصمیم سریع.

### ۵.۶ سبد خرید
- **هدف:** بازبینی بدون تردید + حرکت روان به پرداخت.
- **سکشن‌ها:** لیست اقلام (دوره/محصول با تصویر و قیمت) | خلاصهٔ سفارش (جمع، تخفیف، کد تخفیف) | پیشنهاد مکمل | CTA پرداخت | عناصر اطمینان (پرداخت امن، ضمانت).
- **UX:** تغییر تعداد/حذف با بازمحاسبهٔ زنده؛ کد تخفیف با پیام واضح؛ جمع نهایی همیشه دیده شود.
- **UI:** دو ستون ⅔ اقلام + ⅓ خلاصه (موبایل: خلاصه به‌صورت کارت چسبان پایین).
- **CTA:** «ادامه و پرداخت» — بزرگ و تک‌رنگ.

### ۵.۷ پرداخت (Checkout)
- **سکشن‌ها:** مراحل ۳تایی (`ds-steps`: اطلاعات → پرداخت → تایید) | اطلاعات خریدار | روش ارسال (برای کالا) | **درگاه‌های پرداخت** (کارت/نمادها) | خلاصهٔ سفارش ثابت | رمز امنیتی.
- **UX:** فقط فیلدهای ضروری؛ خطا inline زیر فیلد؛ بازگشت بدون از دست رفتن داده.
- **اعتمادسازی:** لوگوی درگاه‌ها، پیام «اتصال امن SSL»، شمارهٔ پشتیبانی.
- **CTA:** «پرداخت امن و نهایی کردن سفارش».

### ۵.۸ ورود / ثبت‌نام
- **سکشن‌ها (قالب از صفحه‌ساز):** برند کوتاه + مزیت ۳تایی | فرم | لینک‌های ریکاوری | اعتماد (نمادها).
- **UX:** فرم حداقلی (موبایل/ایمیل + رمز)، نمایش رمز با چشم، قدرت رمز زنده، ورود با کد یک‌بارمصرف؛ بعد از ورود هدایت هوشمند (ادامهٔ یادگیری یا سبد نیمه‌کاره).
- **UI:** کارت وسط‌چین `ds-card` + پس‌زمینهٔ برند ملایم؛ دکمهٔ اصلی تمام‌عرض `btn-xl`.
- **CTA:** «ورود به حساب» / «ساخت حساب رایگان».

### ۵.۹ پروفایل کاربر
- **سکشن‌ها:** هدر پروفایل (آواتار، نام، سطح، نوار پیشرفت) | تب‌ها (اطلاعات، امنیت، اعلان‌ها، کیف پول) | فرم‌های استاندارد `ds-field`.
- **UX:** ذخیرهٔ خودکار/دکمهٔ مشخص؛ تغییر رمز و شماره با تایید دومرحله‌ای.

### ۵.۱۰ داشبورد دانشجو
- **هدف:** «ادامهٔ یادگیری» در کمتر از ۵ ثانیه.
- **سکشن‌ها:** خوش‌آمد + آمار (دورهٔ من، ساعت یادگیری، استریک) | **کارت ادامهٔ یادگیری** (آخرین درس + درصد پیشرفت `ds-progress`) | دوره‌های من | آزمون‌ها/تکالیف نزدیک | سفارش‌ها و فاکتورها | تیکت‌ها | گواهی‌های من.
- **ویرایش:** چیدمان داشبورد از صفحه‌ساز (ویجت داینامیک داشبورد با خاموش/روشن‌کردن بخش‌ها).
- **UX:** اولویت با «ادامهٔ دهم برو»؛ حالت خالی هر بخش با CTA (مثلاً «دوره‌ای نداری → مشاهدهٔ دوره‌ها»).

### ۵.۱۱ پنل مدرس
- **سکشن‌ها:** داشبورد درآمد و دانشجو (نمودار) | مدیریت دوره‌ها (جدول) | جلسات و محتوا | تیکت‌های دانشجو | تسویه‌حساب.
- **UI:** چیدمان سایدبار تیره + محتوای روشن؛ جدول‌های `ds-table` با اکشن inline.

### ۵.۱۲ پنل مدیریت
- **سکشن‌ها:** دسته‌بندی نقش‌محور منو (محتوا / فروش / کاربران / صفحه‌ساز / تنظیمات) | جستجوی سریع منو | داشبورد KPI | جدول‌های مدیریتی | فرم‌های تنظیمات `ss-card`.
- **UX:** حداکثر ۲ سطح منو؛ عملیات‌های پرتکرار حداکثر ۲ کلیک فاصله؛ تایید مخرب‌ها با مودال.

### ۵.۱۳ جستجو و فیلتر (سراسری)
- جستجوی هدر با دستهٔ انتخابی + پیشنهاد زنده؛ صفحهٔ نتیجهٔ ترکیبی (دوره/محصول/مقاله) در تب؛ فیلترهای chip قابل حذف تک‌تک.

### ۵.۱۴ بلاگ + جزئیات مقاله
- لیست: کارت تصویر + دسته + تاریخ شمسی؛ سایدبار پربازدید/برچسب.
- جزئیات: تیتر، متا، محتوا با `--ds-measure`، باکس نویسنده، مقالات مرتبط، CTA ظریف «دورهٔ مرتبط» در انتهای مقاله (تبلیغ محتوامحور).

### ۵.۱۵ درباره ما / تماس با ما / پشتیبانی / FAQ
- **درباره ما:** تایم‌لاین (`timeline`) + ارزش‌ها + تیم + آمار واقعی.
- **تماس:** کارت‌های روش تماس + فرم `ds-field` + نقشه.
- **پشتیبانی:** تیکت جدید + تاریخچهٔ تیکت‌ها + مقالات راهنما (آکاردئون).
- **FAQ:** دسته‌بندی + آکاردئون بومی + جستجوی سوال.

### ۵.۱۶ صفحه تخفیف‌ها
- **سکشن‌ها:** بنر کمپین (`discount_banner` با شمارش معکوس و کد کپی‌شو) | شمارش معکوس سراسری | گرید `special_offers` | قوانین شفاف تخفیف | خبرنامهٔ اطلاع از تخفیف بعدی.
- **CTA:** «مشاهده و خرید با تخفیف» + دکمهٔ کپی کد.
- **تبدیل:** تایمر واقعی (نه جعلی)، درصدهای واقعی دیتابیس، پرهیز از «همیشه تخفیف».

### ۵.۱۷ صفحات فرود (Landing)
- قالب آمادهٔ کمپین: هیرو تک‌هدف → درد و راه‌حل (`brand_intro`) → اثبات (آمار/نظر) → سرفصل محتوا (`curriculum`) → مدرس (`instructor`) → پلن‌ها (`plans_compare`/`membership`) → FAQ → فرم ثبت‌نام (`form`) → شمارش معکوس.
- **قانون:** هر لندینگ فقط یک کنش (ثبت‌نام/خرید)؛ منو حداقلی؛ فرم بالای تاشو.

### ۵.۱۸ هدر / فوتر / منوی موبایل
- **هدر:** نوار بالا (پشتیبانی/شبکه‌ها) | لوگو | جستجوی بزرگ | منوی مگا دسته‌ها | اقدامات (سبد با شمارنده، علاقه‌مندی، ورود/پروفایل) — کاملاً از صفحه‌ساز.
- **فوتر:** دربارهٔ کوتاه + نمادها | لینک‌های دسته‌بندی‌شده | اطلاعات تماس | خبرنامه | روش‌های پرداخت | کپی‌رایت شمسی.
- **موبایل:** نوار پایین ۵تایی (خانه/دسته‌ها/جستجو/سبد/پروفایل) + منوی کشویی صفحه‌ساز‌شده.

## ۷) اصول جهانی اعتمادسازی و نرخ تبدیل

1. **شفافیت قیمت** — قیمت نهایی، درصد تخفیف و مدت دسترسی همیشه قبل از کلیک دیده شود.
2. **کاهش ریسک** — ضمانت ۷ روزه، پیش‌نمایش رایگان، مشاهدهٔ سرفصل کامل قبل از خرید.
3. **اثبات اجتماعی واقعی** — فقط نظرات تاییدشده و آمار واقعی دیتابیس (تگ‌های پویا `{courses}` و …).
4. **اعتبار رسمی** — نماد اعتماد، ساماندهی، گواهی قابل استعلام با کد.
5. **فومو مسئولانه** — شمارش معکوس و ظرفیت فقط وقتی واقعی است؛ کد تخفیف با کپی یک‌کلیکی.
6. **مسیر کوتاه** — از هر صفحه حداکثر ۲ کلیک تا سبد؛ دکمهٔ اصلی همیشه هم‌رنگ برند و بزرگ‌تر از ثانویه.
7. **بازخورد فوری** — toast برای هر کنش، skeleton برای لود، خطای inline در فرم‌ها.
8. **موبایل‌اول** — نوار پایین، دکمه‌های ≥ 44px، فرم‌های تک‌ستونه با کیبورد مناسب.

## ۸) راهنمای فنی پیاده‌سازی

### فایل‌های کلیدی این بازطراحی
| فایل | نقش |
|---|---|
| `static/css/design-system.css` | **جدید** — کل لایهٔ توکن‌ها و کامپوننت‌های v2 + دارک مود + استایل ۱۳ بلوک جدید |
| `blueprints/builder.py` | تعریف ۱۳ ویجت جدید + توابع داینامیک `builder_special_offers` و `builder_related_products` و `countdown_secs` |
| `templates/builder/blocks.html` | رندرر ۱۳ بلوک جدید + سایه/حاشیه در `widget_style` + کلاس `pb-hidden-t` |
| `static/js/builder.js` | کنترل سایه و رنگ حاشیه در تب استایل + چک‌باکس «مخفی در تبلت» (ویجت و سکشن) |
| `templates/partials/course_card.html` | کارت دوره v2 (آیکون‌های Tabler، ساختار جدید، رفتارهای حفظ‌شده) |
| `designs.py` | طرح صفحهٔ اصلی **«مدرن ۲۰۲۶» (کد ۶)** با تمام بلوک‌های جدید |
| `app.py` | ثبت توابع داینامیک جدید در Jinja |
| `templates/base.html`، `templates/builder/editor.html` | لود `design-system.css` |

### فعال‌سازی و استفاده
1. **پیش‌فرض جدید:** در پنل مدیریت → طراحی → طرح صفحهٔ اصلی → **«صفحه اصلی — مدرن ۲۰۲۶»**.
2. **بلوک‌های جدید:** صفحه‌ساز → پالت «بخش‌های صفحه» و «فروش» (۱۳ بلوک جدید در بالای فهرست).
3. **نمایش تفکیکی دستگاه‌ها:** تب «پیشرفتهٔ» هر سکشن/ویجت → مخفی در موبایل/تبلت/دسکتاپ.
4. **دارک مود:** `document.documentElement.dataset.theme='dark'` (زیرساخت CSS آماده است؛ سوییچ در هدر قابل افزودن با ویجت HTML).
5. **رنگ برند:** توکن‌ها از تم فعلی ارث می‌برند؛ تغییر رنگ از تنظیمات طراحی بدون دست‌زدن به CSS.
