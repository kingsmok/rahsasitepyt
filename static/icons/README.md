# 🎨 Tabler Icons — 390 آیکون

مجموعه آیکون‌های [Tabler Icons](https://tabler.io/icons) — نسخه 3.31 — لایسنس **MIT**
(استفاده آزاد، تجاری و شخصی، بدون نیاز به ذکر منبع، ولی منبع ذکر شده است.)

## استفاده در قالب‌ها
```jinja
{{ icon('heart', 20) }}              ← اندازه ۲۰
{{ icon('heart', 24, 'text-danger') }} ← با کلاس CSS (رنگ از currentColor)
{{ icon('cart', 18, '', 'سبد خرید') }} ← با tooltip
```

## مرور آیکون‌ها
پنل مدیریت ← ⚙️ فنی ← 🎨 آیکون‌ها (کلیک = کپی کد)

## افزودن آیکون جدید
```bash
curl -o static/icons/name.svg https://cdn.jsdelivr.net/npm/@tabler/icons@3.31.0/icons/outline/name.svg
```
سپس سرور را ری‌استارت کنید (آیکون‌ها یک‌بار در حافظه بارگذاری می‌شوند).
