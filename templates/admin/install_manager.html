🔒 راهنمای اتصال به مخازن خصوصی (Private / گرایوت) در GitHub:
  • روش ۱ (توکن شخصی PAT): در گیت‌هاب یک Personal Access Token (یا Fine-grained token) با دسترسی Read ایجاد کنید و آدرس مخزن را به شکل زیر وارد نمایید:
    https://YOUR_TOKEN@github.com/username/repo.git
  • روش ۲ (کلید SSH - Deploy Key): کلید عمومی سرور (~/.ssh/id_ed25519.pub) را در تنظیمات مخزن (بخش Deploy Keys) اضافه کرده و آدرس SSH را وارد کنید:
    git@github.com:username/repo.git
  • به‌روزرسانی اتوماتیک دیتابیس چگونه کار می‌کند؟ پس از جایگزینی کدها (git reset --hard)، تابع _migrate_db() به‌صورت اتوماتیک اجرا شده، جدول‌های جدید را ایجاد کرده و ستون‌های جدید اضافه شده به models.py را با دستور ALTER TABLE ADD COLUMN به دیتابیس فعلی اضافه می‌کند بدون اینکه داده‌ای پاک شود.
