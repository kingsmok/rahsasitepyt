⚡ راهکار جذاب و فوری اتصال به زمپ (XAMPP)

ویژه ویندوز و توسعه محلی

برای اجرای پروژه روی زمپ (XAMPP)، نیازی به ساخت دستی دیتابیس در phpMyAdmin یا پیکربندی پیچیده ندارید! نام دیتابیس دلخواه خود را وارد کنید؛ سیستم به‌صورت خودکار به MySQL زمپ (root@localhost:3306 بدون رمز) متصل می‌شود و در صورت عدم وجود، دیتابیس را اتوماتیک ایجاد می‌کند.

💡 نکته: مطمئن شوید در کنترل‌پنل XAMPP، سرویس‌های Apache و MySQL روشن (Start) باشند.

⏳ پیشرفت به‌روزرسانی:

🔒 راهنمای اتصال به مخازن خصوصی (Private / گرایوت) در GitHub:
  • روش ۱ (توکن شخصی PAT): در گیت‌هاب یک Personal Access Token (یا Fine-grained token) با دسترسی Read ایجاد کنید و آدرس مخزن را به شکل زیر وارد نمایید:
    https://YOUR_TOKEN@github.com/username/repo.git
  • روش ۲ (کلید SSH - Deploy Key): کلید عمومی سرور (~/.ssh/id_ed25519.pub) را در تنظیمات مخزن (بخش Deploy Keys) اضافه کرده و آدرس SSH را وارد کنید:
    git@github.com:username/repo.git
  • به‌روزرسانی اتوماتیک دیتابیس چگونه کار می‌کند؟ پس از بررسی فایل‌های ضروری و جایگزینی commit، مایگریشن در یک Python process تازه اجرا می‌شود تا مدل‌های نسخهٔ جدید خوانده شوند؛ جدول‌ها و ستون‌های جدید و indexها اضافه می‌شوند و default ستون‌های تازه برای رکوردهای قدیمی تکمیل می‌شود، بدون اینکه رکورد موجودی حذف شود.

🧹 بازنشانی کامل دیتابیس (نصب دوباره از صفر)

همهٔ جدول‌ها پاک شده و دیتابیس دقیقاً مثل اولین نصب از نو ساخته می‌شود (تنظیمات، دسته‌بندی‌ها و حساب مدیر). قبل از شروع یک نسخهٔ بکاپ کامل در instance/backups/ ساخته می‌شود — با آن می‌توانید به حالت قبل برگردید. این عملیات فقط برای دیتابیس محلی SQLite و فقط توسط مدیر کل امکان‌پذیر است.

⚠️ همهٔ کاربران، دوره‌ها، سفارش‌ها، نظرات، تیکت‌ها، صفحات و محتوای آموزشی حذف می‌شوند. اگر فقط می‌خواهید کدها را به‌روز کنید از «به‌روزرسانی از گیت» بالای همین صفحه استفاده کنید.
